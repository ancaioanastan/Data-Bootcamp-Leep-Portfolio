# 📊 Tableau – Retail & Sales Data Visualisation

## 📌 Project Overview

This project was completed as part of my **Level 3 Data Technician Skills Bootcamp**. It demonstrates my ability to use **Tableau** to explore, analyse, and visualise retail and sales data through interactive dashboards and meaningful visualisations.

The project focuses on transforming data into clear, accessible insights that help identify sales trends, compare performance, and communicate findings to support data-driven decision-making.

## 🎯 Skills Demonstrated

- **Interactive Dashboards:** Designed dashboards to present key sales insights in a clear and engaging format.
- **Data Filtering:** Used filters and interactive selection controls to explore data by relevant categories and dimensions.
- **Calculated Fields:** Applied calculated fields to derive additional insights and support data analysis.
- **Data Visualisation:** Created a variety of charts, including bar charts, line charts, pie charts, and geographic maps, to communicate different aspects of the data.
- **Trend Analysis:** Visualised sales performance and patterns to support comparisons across categories, locations, and time periods.
- **Data Storytelling:** Presented information visually to make patterns, relationships, and key findings easier to understand.

## 📈 Key Project Features

- Interactive dashboards for exploring retail and sales performance.
- Multiple visualisation types selected to suit different analytical questions.
- Filters that allow users to investigate specific segments of the data.
- Calculated fields to enhance analysis and provide additional context.
- Visual representations of sales trends, category comparisons, and geographic data.

## 💡 Key Learning Outcomes

Through this project, I developed practical experience in using Tableau to turn raw data into informative visualisations. I strengthened my understanding of how to select appropriate chart types, build interactive dashboards, and communicate analytical findings through data storytelling.

The project also reinforced the importance of presenting data in a way that helps users explore information, recognise patterns, and make informed decisions.

## 🛠️ Tools & Technologies

- **Tableau** – Data visualisation, calculated fields, filters, and interactive dashboards
- **Retail & Sales Data** – Data exploration, performance analysis, and visual reporting
