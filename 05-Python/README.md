# Core Python Fundamentals & Interactive Logic

## 📌 Project Overview

This project was developed during the **Data Technician Bootcamp** to demonstrate core Python programming fundamentals. The primary objective was to apply foundational concepts—such as dynamic user input handling, conditional control flow, iterative loops, and basic calculation logic—to build interactive command-line applications and process basic data workflows.

## 🛠️ Key Skills & Tools Demonstrated

* **User Interaction:** Utilizing `input()` to accept user data dynamically and `print()` (along with f-strings) to display formatted, readable output.

* **Data Types & Type Casting:** Defining variables and converting data types using `int()`, `float()`, and `str()` to prepare raw inputs for numerical computations.

* **Conditional Logic:** Implementing `if`, `elif`, and `else` statements to guide execution flow based on user decisions or numerical thresholds.

* **Iterative Control Flow:** Leveraging `for` loops for sequence processing and `while` loops for continuous execution, menu navigation, and input validation.

* **Mathematical Calculations:** Performing automated arithmetic operations, aggregations, and running totals.

## 🔍 Workflow & Implementation

### 1. User Input & Dynamic Interaction

* Used `input()` to prompt users for information such as transaction amounts, operational choices, or repeat counts.

* Converted string-based input into appropriate numeric types via explicit **type casting** (`int()`/`float()`) to prevent runtime errors during mathematical calculations.

### 2. Decision Making & Logic

* Built robust conditional branches (`if`/`elif`/`else`) to evaluate user inputs, score thresholds, or operational categories.

* Enforced validation logic to handle invalid options gracefully before executing calculations.

### 3. Loop Execution & Iteration

* Created `while` loops to keep applications active until the user explicitly chooses to exit, enabling continuous interaction.

* Utilized `for` loops to iterate over defined numerical ranges or lists to automate repetitive calculations and summary metrics.

## 💡 Example Use Cases Built

* **Interactive Command-Line Tool:** A menu-driven terminal interface powered by `while` loops and nested `if` statements.

* **Automated Calculator:** Performs numerical calculations based on dynamic input with type casting validation.

* **Data Aggregator:** Collects series of numerical inputs over repeated iterations to calculate totals and averages.
