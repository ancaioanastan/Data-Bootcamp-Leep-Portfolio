# Azure Data Fundamentals (DP-900) – Cloud Computing & Data Services

## 📌 Project Overview

This project was completed as part of the **Level 3 Data Technician Skills Bootcamp with Leep Talent**, focusing on cloud computing concepts and Microsoft Azure Data Fundamentals (DP-900).

The project developed foundational knowledge of cloud infrastructure, Azure data services, data storage, data integration, and analytical workloads. Through practical Skillable labs, research activities, and business scenarios, I explored how organisations can use cloud technologies to store, manage, integrate, and analyse data to support informed business decisions.

## 🎯 Learning Objectives

- Understand cloud computing fundamentals, including scalability, flexibility, cost management, and shared infrastructure.
- Compare cloud service models: Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS).
- Explore public, private, hybrid, and community cloud deployment models.
- Understand relational and non-relational data storage options in Microsoft Azure.
- Explore Azure services for data integration, storage, API management, and analytics.
- Develop awareness of data protection, security, compliance, and responsible data handling.

## ☁️ 1. Cloud Computing Fundamentals

Explored the role of cloud computing in modern business, including how organisations can access computing resources over the internet instead of maintaining all their own physical infrastructure.

Key concepts included:

- **Cost management:** Reducing upfront hardware investment and estimating cloud service costs.
- **Scalability:** Adjusting computing and storage resources as demand changes.
- **Accessibility and collaboration:** Supporting access to applications and data across locations.
- **Cloud service models:** Comparing IaaS, PaaS, and SaaS.
- **Deployment models:** Understanding public, private, hybrid, and community cloud environments.
- **Risk awareness:** Considering unexpected usage costs, security misconfigurations, migration risks, and regulatory compliance.

## 🗄️ 2. Azure Data Storage: Relational and Non-Relational Data

Explored different approaches to storing data, based on its structure and the needs of the application.

### Azure SQL Database – Relational Data

Investigated relational database fundamentals through the *Explore Azure SQL Database* practical lab.

Key learning areas:
- Structured data organised into tables, rows, and columns.
- Relationships between datasets and the importance of data consistency.
- Potential applications for transactional data, including retail sales, customer records, and inventory.

### Azure Storage Account and Azure Cosmos DB – Non-Relational Data

Explored non-relational data storage through the *Explore Azure Storage for Non-Relational Data* lab.

Key learning areas:
- Cloud storage for files and other data assets.
- Non-relational data structures for flexible data storage.
- Understanding how Azure Storage and Cosmos DB support different storage and application requirements.

## 🔄 3. Data Integration and Azure Services

Investigated how Azure services can help organisations collect, integrate, and move data between different systems.

- **Azure Data Factory:** Explored data ingestion, transformation, and pipeline orchestration for combining data from different sources.
- **Azure HDInsight:** Learned about large-scale data processing using frameworks such as Apache Spark, Hive, Kafka, and Hadoop.
- **Azure API Management:** Examined how APIs can be published, secured, monitored, and managed to enable communication between applications and backend services.

These concepts demonstrated how data integration supports the movement of information from operational systems into environments used for analysis and reporting.

## 📊 4. Microsoft Fabric and Analytical Workloads

Completed practical learning activities exploring the fundamentals of large-scale data analytics and real-time analytics in Microsoft Fabric, alongside introductory Power BI data visualisation concepts.

The learning focused on:
- Understanding analytical workloads and how they differ from transactional workloads.
- Exploring how data can be integrated, stored, and prepared for analysis.
- Investigating real-time analytics concepts and event-driven data processing.
- Understanding how visualisation tools can communicate patterns and trends to support decision-making.

The workbook also introduced the role of data formats, including CSV, JSON, and Parquet, in data storage and analytical workflows.

## 🔐 6. Data Security, Privacy and Compliance

Explored the importance of protecting organisational and customer data when adopting cloud technologies.

Topics included:
- UK GDPR and the Data Protection Act 2018.
- Data minimisation, appropriate use, and retention of personal information.
- Encryption and access controls for cloud-hosted data.
- Cybersecurity risks, including unauthorised access and service disruption.
- Backup, disaster recovery, and business continuity considerations.

These concepts are important when working with customer details, sales transactions, and other business information.

## 💡 Key Takeaways

This project strengthened my foundational understanding of:

- Cloud computing principles and service models.
- The differences between relational and non-relational data.
- The purpose of key Azure storage, integration, and analytics services.
- How data ingestion and integration contribute to analytical workflows.
- The role of Microsoft Fabric and Power BI in data analytics.
- How organisations can use cloud data services to support reporting and business decisions.
- The importance of security, compliance, and cost management when working with cloud data.
