# SQL Project – Data Technician Skills Bootcamp

## 📌 Project Overview

This project was completed as part of the **Level 3 Data Technician Skills Bootcamp with Leep Talent**. It demonstrates practical SQL skills for querying relational databases, extracting relevant information, combining data from multiple tables, and generating insights to support business decision-making.

Using the **Northwind Traders retail database** in Supabase, I worked through real-world business scenarios involving customers, products, suppliers, categories, orders, and sales quantities. I also completed SQL exercises using a World database to practise querying and analysing geographical and demographic data.

## 🎯 Project Objectives

- Retrieve and filter data to answer specific business questions.
- Organise query results to make information easier to interpret.
- Combine related datasets using SQL JOINs.
- Summarise and aggregate data to support reporting and analysis.
- Apply SQL to practical retail, sales, inventory, and business reporting scenarios.

## 🛠️ Technical Skills Demonstrated

| SQL Skill | Practical Application |
|---|---|
| `SELECT` | Retrieve specific columns or complete records from database tables. |
| `WHERE` | Filter customers, products, and orders using business criteria. |
| `DISTINCT` | Identify unique customer locations without duplicate values. |
| `ORDER BY` | Sort products by price, customers alphabetically, and orders by date. |
| `GROUP BY` | Group records by category and calculate summary statistics. |
| Aggregate functions | Use `COUNT()`, `SUM()`, and `AVG()` to summarise data. |
| `INNER JOIN` | Combine products with their categories and suppliers, and link orders to customers and employees. |
| `LEFT JOIN` | Retain all categories or products when matching records may be absent. |
| `BETWEEN`, `LIKE`, `AND`, `OR` | Apply ranges, text matching, and multiple filtering conditions. |
| `LIMIT` and `OFFSET` | Restrict query results and retrieve selected sections of ranked data. |
| Calculated fields | Calculate population density and average population values. |
| SQL aliases | Improve column labels and make queries easier to understand. |

## 📊 Business Analysis Examples

### 1. Retail and Product Analysis
- Identified products priced above £50 and products within a specified price range.
- Retrieved product names alongside category and supplier information.
- Filtered products by category, including Meat/Poultry.
- Analysed product quantities ordered to explore sales volume.

### 2. Customer and Order Analysis
- Retrieved customer names and locations for marketing activities.
- Filtered customers by country and city to support targeted campaigns.
- Sorted orders by date to identify recent transactions.
- Combined orders with customer and employee records to create a more complete order overview.
- Filtered orders by year for historical reporting.

### 3. Inventory and Category Reporting
- Counted products within each category.
- Used a `LEFT JOIN` to retain categories even when they had no matching products.
- Combined product, category, and supplier data to support inventory and supply-chain reporting.

### 4. Data Exploration and Aggregation
- Counted cities and identified the most and least populated cities in the World database.
- Identified countries with the highest life expectancy and population.
- Calculated population density using population and surface area.
- Used filtering, sorting, grouping, and joins to answer structured research questions.

- Translating business requirements into SQL queries and meaningful reports.
