# Power BI Retail & Sales Data Analysis

## Project Overview

This project was completed as part of my **Data Technician Skills Bootcamp** and demonstrates my ability to transform raw data into meaningful business insights using **Microsoft Power BI**.

The project focused on analysing retail and sales data, preparing datasets for analysis, and developing interactive reports to explore sales performance, identify trends, and communicate insights through effective data visualisation.

## Key Skills Demonstrated

- **Data Cleaning & Transformation:** Used Power Query to clean, transform, and prepare data for analysis, improving data quality and consistency.
- **Data Visualisation:** Created a range of visualisations, including bar charts, line charts, pie charts, and maps, to present sales data clearly and effectively.
- **DAX Calculations:** Applied DAX to create calculated columns and measures to support data analysis and reporting.
- **Interactive Reporting:** Built interactive reports using slicers and filters, enabling users to explore data by different categories and dimensions.
- **Data Analysis & Storytelling:** Used visualisations to highlight sales patterns, trends, and comparisons, turning data into accessible business insights.
- **Report Design:** Organised report elements into a clear, user-friendly layout to support exploration and interpretation of retail performance.
